FAQ

Download FAQ

Is there an official Azeroth Survivors download?

Yes — the official Windows client is linked from the developer's official site, wow.aethus.pl. We link official sources only and never host game files ourselves.

Is the download safe?

Download only from the official site. The game is free — any page asking payment is not official. Avoid re-packed .rar or .torrent copies from third parties; they are unofficial and can be modified.

Is there a Steam version?

No. There is no Steam page at the time of writing (checked 2026-11-10). The official channels are the browser version and the Windows client.

Can I play on Mac or Linux?

Yes, via the browser: any current WebGPU-capable browser works. On Linux Chrome, WebGPU may need enabling at chrome://flags/#enable-unsafe-webgpu. Community guides also cover Steam Deck.

Does the Windows client need an account?

No — like the browser version, the official Windows client asks for no account and no payment.
